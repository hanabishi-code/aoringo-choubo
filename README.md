# 経理ノート

個人事業主向けの、Mac で動く複式簿記アプリです。取引を入力すると、仕訳帳・総勘定元帳・損益計算書・貸借対照表を作り、請求書も発行できます。

- **完全オフライン**: インターネットには一切接続しません(アプリの設定で外部との通信を禁止しています)
- **データはこの Mac の中だけ**: クラウドやサーバーには送りません
- **自動バックアップ**: 起動時と終了時に自動で保存し、いつでもその時点に戻せます

> [!WARNING]
> **税務上の正確性は保証しません。** 計算結果は申告の参考としてご利用いただき、最終的な判断は税理士・税務署などにご確認ください。詳しくは「[免責事項](#免責事項)」をご覧ください。

## 主な機能

- 取引の入力(収入・経費・仕入・事業主貸/借・未払計上・借入と返済 など)と、仕訳帳・総勘定元帳の自動作成
- 損益計算書・貸借対照表、固定資産の減価償却(定額法)、期首・期末の棚卸高
- 請求書の作成と印刷
- レシート・領収書の画像の添付(JPEG / PNG / iPhone の HEIC)
- 取引一覧・損益計算書の CSV 書き出し
- 変更履歴(いつ・何を追加/修正/削除したか)の閲覧
- 自動バックアップからの復元、バックアップファイル(JSON)の書き出し・取り込み

## 動作環境

- macOS 11 以降(対応する CPU の種類は、配布ビルドの準備時に記載します)

## インストール

> 配布用のビルド(GitHub Releases)は準備中です。

このアプリは Apple の署名・公証を受けていません。そのため、初めて開くときに「開発元を検証できません」などの警告が出て開けません。次の手順で開いてください。

1. ダウンロードした `.dmg` を開き、「経理ノート」を「アプリケーション」フォルダにドラッグします
2. 「経理ノート」をダブルクリックします(警告が出たら「完了」または「キャンセル」で閉じます)
3. **システム設定 → プライバシーとセキュリティ** を開き、下の方にある「"経理ノート" は開発元を確認できないため、使用がブロックされました」の横の **「このまま開く」** をクリックします
4. 確認が出たら「開く」をクリックします(Mac のログインパスワードを求められることがあります)

2回目からは、ふつうにダブルクリックで開けます。

## データの保存場所とバックアップ

データはすべて次のフォルダに保存されます。

```
~/Library/Application Support/com.keirinote.desktop/
├── data.json       帳簿データ本体
├── history.jsonl   変更履歴(追記のみ)
├── backups/        自動バックアップ(起動時・終了時)と、復元・取り込み・全削除の前の退避
└── receipts/       レシート・領収書の画像
```

- 自動バックアップは直近30日分と、それより前は各月の最後の1つを残します
- 設定画面の「自動バックアップから復元する」で、一覧から選んでその時点に戻せます(戻す前の状態も自動で退避されます)
- 「すべてのデータを削除する」を使っても、自動バックアップ・削除前の退避・レシート画像はこのフォルダに残ります。完全に消す場合は、このフォルダごと削除してください

### おすすめの設定

帳簿は税法上、原則7年(赤字の年は最長10年)の保存義務があります。Mac の故障や紛失に備えて、次の設定をおすすめします。

- **Time Machine**(システム設定 → 一般 → Time Machine): 外付けディスクなどに自動でバックアップされます。上のデータフォルダも対象です
- **FileVault**(システム設定 → プライバシーとセキュリティ → FileVault): Mac のディスクを暗号化し、紛失・盗難時にデータを読まれにくくします
- 設定画面の「全データをバックアップ(JSON)として保存」で、定期的に Mac の外にも保管する

> [!CAUTION]
> 書き出したバックアップ JSON には、レシート画像も含まれます。レシートには住所やカード番号の一部などが写っていることがあります。持ち出す・人に渡す際は取り扱いに注意してください。

## 開発

### 必要なもの

- Xcode Command Line Tools(`xcode-select --install`)
- Rust(https://rustup.rs)
- Tauri CLI(`cargo install tauri-cli --version "^2"`)

### 起動とビルド

```bash
cd src-tauri
cargo build                      # 開発ビルド
./target/debug/keiri-note        # 開発ビルドを起動
cargo tauri build                # 配布用(.app / .dmg)
```

> [!NOTE]
> `src/index.html` や `legacy/index.html` をブラウザで直接開いても、アプリにはなりません(保存やレシート画像などが動かない、別物の画面になります)。必ず上の方法でアプリとして起動してください。

### 構成

- `src/` — 画面(`index.html` / `styles.css` / `app.js`)
- `src-tauri/` — Mac アプリ側(Tauri v2 / Rust)。データの読み書き・自動バックアップ・変更履歴・画像の保存・保存ダイアログ
- `legacy/` — 旧ブラウザ版(参考用)
- `tests/` — テストとテスト用データ

### テスト

```bash
(cd src-tauri && cargo test)                         # 保存・バックアップ・履歴・画像(Rust 側)
osascript -l JavaScript tests/check_calc.js          # 仕訳・減価償却・損益計算書・貸借対照表
osascript -l JavaScript tests/check_import.js        # バックアップ取り込みの検証
osascript -l JavaScript tests/check_receipt_ipc.js   # レシート画像の受け渡し
osascript -l JavaScript tests/check_history.js       # 変更履歴(強制終了後の後始末の判定)
```

## 減価償却の計算について

- 定額法(平成19年4月1日以後に取得した資産)で、償却率は「減価償却資産の耐用年数等に関する省令」別表第八(耐用年数 2〜50年)を使います
- 取得した年・除却した年は月数で按分します。**1円未満の端数処理(切り捨て / 四捨五入 / 切り上げ)は、税理士・税務署に確認のうえ設定画面で選んでください(初期値は切り捨て)**
- 端数処理を変えると、過去の年の償却費も計算し直されます。申告済みの年と数字が合わなくなるため、年度の途中や申告後には変えないでください
