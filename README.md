# 青りんご帳簿

個人事業主向けの、Mac で動く複式簿記アプリです。取引を入力すると、仕訳帳・総勘定元帳・損益計算書・貸借対照表を作り、請求書も発行できます。

- **完全オフライン**: インターネットには一切接続しません(アプリの設定で外部との通信を禁止しています)
- **データはこの Mac の中だけ**: クラウドやサーバーには送りません
- **自動バックアップ**: 起動時と終了時に自動で保存し、いつでもその時点に戻せます

> [!WARNING]
> **税務上の正確性は保証しません。** 計算結果は申告の参考としてご利用いただき、最終的な判断は税理士・税務署などにご確認ください。詳しくは「[免責事項](#免責事項)」をご覧ください。

## 名前とアイコンについて

- **名前**: 個人事業主の「青色申告」と、青りんご(緑色のりんご)から付けました
- **アイコン**: ギリシャ神話で金のりんごの木の番をする女神たち「ヘスペリデス」にちなみ、帳簿を自分の手元に置いておくアプリ、という意味を込めています
- 本アプリは、Apple Inc. および名前に「りんご」を含むほかのソフトウェア・サービスとは関係ありません

## 主な機能

- 取引の入力(収入・経費・仕入・事業主貸/借・未払計上・借入と返済 など)と、仕訳帳・総勘定元帳の自動作成
- 損益計算書・貸借対照表、固定資産の減価償却(定額法)、期首・期末の棚卸高
- 請求書の作成と印刷(A4・適格請求書の記載事項)。送付済みにすると内容を固定、修正版・再発行・控え、請求書から売上を記録
- 消費税の集計(簡易課税・2割特例・3割特例。申告書作成の参考値)
- 取引・請求書へのファイルの添付(JPEG / PNG / iPhone の HEIC / PDF。原本のまま保存、1つの取引に複数可)
- 取引一覧・損益計算書の CSV 書き出し
- 変更履歴(いつ・何を追加/修正/削除したか)の閲覧
- 検索(仕訳帳・総勘定元帳・取引一覧): 取引先、文字(メモ・取引先・科目・金額)、日付の範囲、金額の範囲を組み合わせて絞り込み
- 口座: 普通預金を口座ごと(○○銀行・△△銀行など)に分けて記録。口座ごとの残高・総勘定元帳、貸借対照表は合計と内訳
- 取引先: 取引・請求書の宛先として登録(▼ の一覧から選ぶか、新しく入力)。「取引先」タブで年ごとの売上・経費・未払金の残高・未入金の請求書を集計、名前の変更・統合
- 自動バックアップからの復元、バックアップファイル(JSON)の書き出し・取り込み
- 画面の色: 自動(Mac の外観に合わせる)・白・黒から選べる(設定の「画面の表示」)

## 動作環境

- macOS 11 以降
- Intel / Apple シリコン(Apple シリコンでの動作は未確認です。問題があれば Issue でお知らせください)

## インストール

> 配布用のビルド(GitHub Releases)は準備中です。

このアプリは Apple の署名・公証を受けていません。そのため、初めて開くときに「開発元を検証できません」などの警告が出て開けません。次の手順で開いてください。

1. ダウンロードした `.dmg` を開き、「青りんご帳簿」を「アプリケーション」フォルダにドラッグします
2. 「青りんご帳簿」をダブルクリックします(警告が出たら「完了」または「キャンセル」で閉じます)
3. **システム設定 → プライバシーとセキュリティ** を開き、下の方にある「"青りんご帳簿" は開発元を確認できないため、使用がブロックされました」の横の **「このまま開く」** をクリックします
4. 確認が出たら「開く」をクリックします(Mac のログインパスワードを求められることがあります)

2回目からは、ふつうにダブルクリックで開けます。

## 最初に設定する項目

設定画面で、次を入力してください。

1. **事業者の情報**: 屋号・氏名・郵便番号・住所・電話・FAX、インボイスの登録番号、振込先(銀行名・支店・種別・口座番号・口座名義)。請求書に表示されます
2. **口座と開始残高**: 預金を口座ごとに分ける場合は「口座(普通預金)」で口座を追加・名前を変更し、帳簿をつけ始める日と、その時点の現金・各口座の残高を入力
3. **消費税**: 課税方式(免税事業者 / 簡易課税 / 本則課税 / 2割特例 / 3割特例)と、簡易課税の場合は主たる事業区分。
   **初期値は「未設定」で、選ぶまで消費税は計算しません**
4. **端数処理**: 「請求書の消費税の端数処理」と「減価償却の端数処理」(どちらも初期値は切り捨て。税理士・税務署に確認のうえ設定してください)

## データの保存場所とバックアップ

データはすべて次のフォルダに保存されます。

```
~/Library/Application Support/com.keirinote.desktop/
├── data.json       帳簿データ本体
├── history.jsonl   変更履歴(追記のみ)
├── backups/        自動バックアップ(起動時・終了時)と、復元・取り込み・全削除の前の退避
└── receipts/       添付ファイル(レシート・領収書・請求書の画像や PDF。原本のまま)
```

- 自動バックアップは直近30日分と、それより前は各月の最後の1つを残します
- 設定画面の「自動バックアップから復元する」で、一覧から選んでその時点に戻せます(戻す前の状態も自動で退避されます)
- 「すべてのデータを削除する」を使っても、自動バックアップ・削除前の退避・レシート画像はこのフォルダに残ります。完全に消す場合は、このフォルダごと削除してください

### おすすめの設定

帳簿は税法上、原則7年(赤字の年は最長10年)の保存義務があります。Mac の故障や紛失に備えて、次の設定をおすすめします。

- **Time Machine**(システム設定 → 一般 → Time Machine): 外付けディスクなどに自動でバックアップされます。上のデータフォルダも対象です
- **FileVault**(システム設定 → プライバシーとセキュリティ → FileVault): Mac のディスクを暗号化し、紛失・盗難時にデータを読まれにくくします
- 設定画面の「全データをバックアップ(JSON)として保存」で、定期的に Mac の外にも保管する

> [!CAUTION]
> 書き出したバックアップ JSON には、添付ファイル(レシート・請求書・写真など)も含まれます。住所やカード番号の一部、写真の撮影場所などが含まれていることがあります。持ち出す・人に渡す際は取り扱いに注意してください。

### 必要なもの

- Xcode Command Line Tools(`xcode-select --install`)
- Rust(https://rustup.rs)
- Tauri CLI(`cargo install tauri-cli --version "^2"`)

### 起動とビルド

```bash
cd src-tauri

./target/debug/keiri-note        # 開発ビルドを起動
```

- **配布するアプリは GitHub Actions 上でビルドしたものだけです。** 手元の Mac でビルドしたアプリは配布しません

## 消費税の集計

「レポート」タブに、その年の消費税の集計を表示します(**申告書作成の参考値です。正確性は保証しません。申告の前に税理士・税務署に確認してください**)。

- 売上の金額は**税込**で入力します。売上ごとに税区分(課税・標準税率 / 課税・軽減税率 / 非課税 / 不課税・対象外 / 免税)と、必要なら事業区分を選べます(雑収入の初期値は非課税)
- 計算は国税庁「消費税及び地方消費税の申告書(簡易課税用)の書き方」の手順・端数処理に従います(課税標準額は税率ごとに千円未満切捨て、差引税額・地方消費税は百円未満切捨て)
- 簡易課税で2種類以上の事業がある場合は、原則計算と特例計算(1種類・2種類で75%以上)を比べ、控除額が最も大きい方法を使います
- 固定資産の売却代金は、消費税では課税売上(第4種)として集計します
- 2割特例(個人事業者は令和8年分まで)・3割特例(令和9年分・令和10年分)にも対応し、対象の年以外では注意を表示します
- 中間納付の額を入力すると、納付税額から差し引きます
- 本則課税は、この版では納付税額を計算しません(経費の税区分は記録できます)
- 税率は、適用開始日つきの表で管理しています(現在: 標準 10%・軽減 8%)

## 請求書(適格請求書)

発行者の名前・登録番号、取引年月日、内容、税率ごとの対価の合計と適用税率、税率ごとの消費税額、宛先を表示します。
印刷は A4 縦・明朝体の一般的な形(御請求書・宛先と敬称(御中/様)・右上に請求書番号・発行日・取引年月日・お支払い期限、自社情報・登録番号、御請求金額、明細、税率ごとの合計と消費税、振込先、備考)です。自社の郵便番号・FAX・振込先(銀行名・支店・種別・口座番号・口座名義)は設定の「事業者情報」で入力します。
明細ごとに 10% / 8%(軽減)を選べ、軽減税率の明細には「※」を付けます。消費税額の端数処理は、1枚の請求書・1つの税率につき1回です。方法(切り捨て / 四捨五入 / 切り上げ、初期値は切り捨て)は設定の「請求書の消費税の端数処理」で選べます。請求書ごとに作成時の方法を保存するので、あとで設定を変えても作成済みの請求書の金額は変わりません。
記載事項(登録番号・宛先・取引年月日など)が足りないまま保存しようとすると、確認を表示します。
請求書は「下書き」で作り、送るときに「送付済みにする」を押します。送付済みにすると、そのときの内容(宛先・自社の情報・振込先・明細・税率・金額)が請求書の中に保存されて固定され、あとで設定や取引先を変えても変わりません。送付済みの請求書は直接は直せないので、直すときは「修正版を作る」で新しい番号の請求書を作ります(印刷に「請求書番号○○の修正」と出ます。元の請求書は残ります)。送付済みの請求書は何度でも印刷でき、「そのまま(再発行)」か「控え(「控」の印付き)」を選べます。
売上の記録は自動では作りません。送付済みの請求書の「売上を記録」を押すと、入力画面に区分(収入)・金額(税込)・取引先・税区分・メモ(請求書 No.)・日付(取引年月日が日付ならその日、期間ならその月の末日)が入った状態で開き、「記録する」を押したときだけ保存されます。8% の明細があるときは、税率ごとに2回に分けて記録します。記録すると請求書に「売上記録済み(○件)」と出て、もう一度押すと二重記録の注意が出ます。
「印刷」で macOS の印刷ダイアログが開きます。ダイアログ左下の「PDF」→「PDFとして保存」で PDF にできます。送った請求書の控えは、PDF で保存してその請求書(または売上の取引)に添付しておくと、電子取引データとして保存できます。
ほかのソフトで請求書を作っている場合は、設定の「画面の表示」で「請求書」のタブを表示しないようにできます(作った請求書は消えません)。
請求書の一覧は、取引先・状態(下書き/送付済み(未入金)/入金済み)・発行日の範囲・合計(税込)の範囲・文字(番号・宛先・明細・備考・取引年月日)で絞り込めます。「取引先」タブの「請求書」から、その取引先の請求書の一覧を開けます。

## 電子取引データの保存(電子帳簿保存法)

メールやダウンロードで受け取った請求書・領収書、メールで送った請求書の控え(PDF など)は、電子取引データとして保存が必要です。

- 取引や請求書に添付すると、**原本のまま**(変換せずに)保存します。添付を外しても、ファイル自体は消さずに残り、外したことは変更履歴に残ります
- 添付ファイルは「開く」で、読み取り専用のコピーを「プレビュー」で開きます(原本は変わりません)
- 「日付・金額」の範囲指定と「取引先」を組み合わせて検索できます(仕訳帳・総勘定元帳・取引一覧)
- 国税庁の「電子取引データの訂正及び削除の防止に関する事務処理規程」のひな形(個人事業者の例)は、国税庁の[参考資料(各種規程等のサンプル)](https://www.nta.go.jp/law/joho-zeikaishaku/sonota/jirei/0021006-031.htm)にあります
- 保存期間は原則7年です。年に1回は「全データをバックアップ(JSON)として保存」で書き出し、Mac の外にも保管することをおすすめします

> [!CAUTION]
> **本アプリが電子帳簿保存法の要件を満たすことは保証しません。** 保存方法は国税庁の資料で確認し、必要に応じて税理士・税務署にご相談ください。
> 写真には撮影場所(位置情報)などが含まれることがあります。書き出したバックアップにも含まれるので、人に渡すときは注意してください。

## 減価償却の計算について

- 定額法(平成19年4月1日以後に取得した資産)で、償却率は「減価償却資産の耐用年数等に関する省令」別表第八(耐用年数 2〜50年)を使います
- 取得した年・除却した年は月数で按分します。**1円未満の端数処理(切り捨て / 四捨五入 / 切り上げ)は、税理士・税務署に確認のうえ設定画面で選んでください(初期値は切り捨て)**
- 端数処理を変えると、過去の年の償却費も計算し直されます。申告済みの年と数字が合わなくなるため、年度の途中や申告後には変えないでください
- 固定資産は「資産・負債」タブの固定資産台帳で登録します。支払い方法(現金・普通預金・未払金)を選ぶと、支払いの仕訳(借方 固定資産 / 貸方 支払い方法)を自動で作ります。台帳の取得日・取得価額・支払い方法を直すと仕訳も直り、台帳から削除すると仕訳も削除されます
  - **あとで払う・分割払い・カード払い**は「未払金」で登録し、実際に払ったときにそのつど「買掛金・未払金を支払う」(未払金)を記録してください
  - 減価償却は支払日ではなく、取得日(使い始めた日)から始まります
- 除却(廃棄)した年・売却した年は、処分した月まで償却します
  - **除却**: 残りの帳簿価額を「固定資産除却損」(経費)にします
  - **売却**: 残りの帳簿価額は経費にせず「事業主貸」、売却代金は「事業主借」として記録します。**事業用資産の売却益は原則として譲渡所得となり、本アプリでは計算しません。税理士・税務署に確認してください**
